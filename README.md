-Actualizacion de html, css y js. Se añadieron nuevas funciones para mejorar la calidad de la web: 
Botones de aumentar y disminuir tamaño, alto contraste y fuente de dislexia. Todo con relacion al 
proposito de la pagina.

-Se agrego el backend, con rutas de programas, mensajes del formulario y usuarios. Todo esto, 
incluyendo el servidor local y la base de datos en Mongo.

-Con el backend agregado, se añadio un nuevo recurso: Iniciar sesion y registrarse. Esto para poder tener
control de las personas que visitan el sitio, ademas de los roles que tendran cada uno. Cada perfil podra
modificarse para evitar incovenientes posteriores.
